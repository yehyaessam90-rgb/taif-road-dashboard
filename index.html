    Publish for everyone (GitHub)

    1. Fill the workbook and check it here using Import (only you see it — stored in your browser).
    2. When correct, click Export what’s loaded (or use your file), rename it to project-data.xlsx.
    3. On GitHub open the repo → folder data/ → Add file › Upload files → drop it → Commit.
    4. GitHub Pages republishes in ~1 minute — every viewer now sees the new data.
    5. Schedule: choose the programme, drop its baseline and update .xer, click Download programme file and upload it to data/ (schedule-dbl.json = Detailed Baseline, schedule.json = Target Plan).
    6. Junction slides: after dropping the slide images click Download slides.json and upload it to data/.
    7. Weekly report: after importing the .docx click Download weekly.json and upload it to data/ (it holds every week imported so far).
    8. Events: after adding letters click Download events.json and upload it to data/.
